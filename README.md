# GlobalPulse Radio

A lightweight, privacy-friendly web radio player for streaming stations from around the world, built as a static site with HTML, CSS, and modular JavaScript (`api.js`, `audio.js`, `i18n.js`).

🔗 **Live Demo:** https://relaxsz.github.io/PulseRadio/

---

## Key Features
- **Search & Filters:** Browse stations by name, music genre, country, and quick picks.
- **Favorites & History:** Save favorite stations and view recently played streams.
- **Audio Controls:** Built-in equalizer (Bass, Mid, Treble), audio visualizer (including fullscreen mode), and sleep timer.
- **Multi-language & Theme:** Switch interface language and toggle light/dark theme.
- **Privacy-first:** No account registration or intrusive user profiling.

## Tech Stack
- Static frontend (`HTML5`, `CSS3`, `JavaScript ES Modules`)
- **Radio Browser API** (with fallback mirrors and request timeouts)
- **Web Audio API** (equalizer and visualizer)
- Hosted on **GitHub Pages** with **Cloudflare Web Analytics**
